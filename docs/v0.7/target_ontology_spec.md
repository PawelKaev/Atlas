# Спецификация оператора TargetOntology

## Определение

TargetOntology - это оператор синтеза новых понятий из противоречащих узлов машины.

## Математическая модель

Пусть M - машина, N - множество узлов, C - множество противоречий.

Для пары узлов (n₁, n₂) ∈ N × N определим:
- contradiction_index(n₁, n₂) ∈ [0, 1]
- stability_ratio(n₁, n₂) ∈ [0, 1]

Синтез возможен если:
1. contradiction_index > 0.6
2. stability_ratio падает более 3 тактов
3. ∃ стратегия синтеза S ∈ {Hegelian, Plotinian, Pragmatic}

## Оператор синтеза

TO: (n₁, n₂, S) → n₃

где:
- n₃ - новый узел (синтез)
- n₃.genealogy = n₁.genealogy ∪ n₂.genealogy ∪ {synthesis_event}
- n₃.properties = merge(n₁.properties, n₂.properties, S)

## Верификация

После синтеза:
1. Симуляция 50 тактов
2. Проверка stability_ratio > 0.5
3. Проверка contradiction_index < 0.6
4. При неудаче - rollback

## Примеры

### Пример 1: Гегелевский синтез
- n₁ = "Тезис" (Идея Блага)
- n₂ = "Антитезис" (Воля к власти)
- n₃ = "Синтез" (Воля к Благу)

### Пример 2: Плотиновская эманация
- n₁ = "Единое"
- n₂ = "Материя"
- n₃ = "Эманация" (промежуточные уровни)

## Интеграция

Синтез интегрируется через SynthesisIntegrator:
1. Добавление узла
2. Связывание с родителями
3. Пересчет метрик
4. Запись в TemporalMap
