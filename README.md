# Atlas

Язык программирования нового поколения.

## Статус

Pre-alpha, активная разработка.

## Быстрый старт

### Требования

- Python 3.11+
- Rust 1.75+
- LLVM/Clang 22+

### Установка

git clone https://github.com/PawelKaev/Atlas.git
cd Atlas
python -m venv .venv
.venv\Scripts\activate
pip install maturin
cd grammalang-core
maturin develop --release
cd ..

### Первая программа

функция main():
    написать("Привет, мир!")

python main.py собрать привет.at
